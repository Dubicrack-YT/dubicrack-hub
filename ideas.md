# Dirección de diseño: Dubicrack Hub

## Tres aproximaciones exploradas

### 1. Directorio de señales
**Muy breve:** Un explorador de enlaces inspirado en el comando `ls`, con listados de alto contraste y metadatos de actividad. Mantiene la terminal como herramienta de navegación, no como decoración.

**Probabilidad:** 0.06

### 2. Consola de creador
**Muy breve:** Una estación de mando con YouTube y GitHub como canales activos. El diseño prioriza avances, hitos y contenido reciente sin parecer una red social genérica.

**Probabilidad:** 0.04

### 3. Archivo CRT personal
**Muy breve:** Un archivo monocromo de estética retro, con marcos de monitor y ruido visual sutil. Evoca una colección personal preservada en una terminal.

**Probabilidad:** 0.09

## Dirección elegida: Directorio de señales

### Movimiento de diseño
**Editorial técnico con terminal UNIX de lectura rápida.** La interfaz conserva el vocabulario de comandos de Dubicrack Hub, pero lo organiza como un directorio vivo de canales y proyectos.

### Principios centrales

1. **Navegación como comando:** cada enlace se presenta como una entrada consultable, con destino y estado claros.
2. **Contenido antes que ornamento:** la información de YouTube y GitHub se lee sin simulaciones innecesarias.
3. **Contraste funcional:** fondo grafito, texto marfil y acentos distintos para cada canal.
4. **Adaptación honesta:** la jerarquía se reorganiza en móvil sin ocultar rutas, acciones ni contexto.

### Filosofía de color

El grafito oscuro sostiene la sensación de terminal. El verde Dubicrack se usa para prompt, foco y disponibilidad; YouTube conserva rojo suave y GitHub usa turquesa. Cada acento identifica una fuente, no una sección decorativa.

### Paradigma de distribución

Una cabecera de sesión, un índice de directorios persistente en escritorio y una zona de resultados adaptable. En móvil, las rutas y controles se convierten en una secuencia vertical legible.

### Elementos distintivos

1. Barras de ruta y metadatos de actualización.
2. Entradas de directorio con permisos, origen y acción visible.
3. Un cursor de terminal y líneas de registro que señalan el estado de carga.

### Filosofía de interacción

Los enlaces responden como comandos: foco inmediato, etiquetas explícitas y feedback de carga o error en el mismo lenguaje visual. No se simulan herramientas administrativas que no existen.

### Animación

Las filas aparecen con una entrada breve de 8 px y los indicadores de carga pulsan suavemente. La duración máxima es 220 ms y se respeta `prefers-reduced-motion`.

### Sistema tipográfico

**Space Grotesk** para titulares y **JetBrains Mono** para rutas, comandos y metadatos. Las acciones usan mayúsculas pequeñas y espaciado de terminal; los textos de lectura conservan interlineado amplio.

### Esencia de marca

**Dubicrack Hub reúne los canales y proyectos de Dubicrack en un directorio web directo, navegable y con contexto.** Personalidad: curiosa, clara y técnica.

### Voz de marca

Los textos describen la acción real y el destino. Ejemplos: “Abrir canal de Dubicrack” y “Consultar repositorios recientes”.

### Logotipo y símbolo

Un prompt `>_` construido en bloques con una marca de cursor verde, acompañado por el nombre DUBICRACK con cortes rectangulares discretos.

### Color distintivo

**Verde señal `#9CFF6D`**, reservado para navegación, foco y actividad confirmada.
